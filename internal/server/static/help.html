Writing pages

Pages are written in Markdown. The most useful bits:

You typeYou get
# Title, ## SectionHeadings (the first one is the page title)
**bold**, *italic*, ~~struck~~, `code`bold, italic, struck, code
[Missing pet](/foolslanding/notice/missingpet)A link to a page: use the address shown in the browser
[Elsewhere](https://example.com)An external link
![A map](/_media/foolslanding/map.jpg)An image
<img src="/_media/x.jpg" width="200" align="right">A smaller image, floated right
- item / 1. itemBulleted / numbered lists (indent 4 spaces to nest)
> quoted textA quote
Text[^1] … [^1]: The note.A footnote
---A horizontal line

Page listings

```list
ns: skarnholm/notice
sort: created
reverse: true
pictures: true
```

Options: ns, exclude, sort (title, id, created, modified), reverse, columns, numbered, pictures, recursive, namespaces, tree, heading.

Shortcuts

e edits the page, / jumps to search, Ctrl+S saves while editing.
