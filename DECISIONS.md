# Decisions

Calls made while building, with the reason. Newest at the bottom of each section.
"Revisit" marks the ones worth a second look.

## Scope and process

- **Migration is a one-off script**, kept in `migrate/` for reference, not a reusable DokuWiki importer. It is re-run while conversion bugs are fixed; once the output is good, `lodge-data` becomes the source and later fixes are made there directly.
- **Layouts, widgets and data files are committed straight into `lodge-data`** after the import, not generated by the script.
- **Login during development: a single local admin account** (user's choice). Users and Discord login come later.

## Content format

- **Pages are CommonMark + GFM** (tables, strikethrough, autolinks) with footnotes and raw HTML allowed. Optional YAML frontmatter.
- **Links and images are standard markdown**, using the page's URL path (`[Label](/ns/page)`, `![alt](/_media/ns/img.jpg)`). Old `[[link]]`s without a label get the target page's title at conversion. Reason: plain markdown everywhere, and a URL copied from the address bar is a valid link.
- **Sized or aligned images use an HTML `<img>` tag** (`width`, `align`); the server scales images to the requested width.
- **Page ids are normalised the DokuWiki way** (lowercase, accents stripped, punctuation and spaces to `-`), so old ids map onto new paths predictably.
- **Boxes and styled text are HTML with a class** (`<div class="spoiler">`, `<span class="badaawi">`), replacing the wrap plugin. CSS selectors are renamed from `.wrap_x` to `.x`.
- **The only additions to markdown are frontmatter and fenced code blocks with the `list` and `widget` languages** (YAML bodies). They show as code in other viewers. No `:::` containers, no `::` directives, no wiki-link syntax.
- **Complex tables (colspan, rowspan, header cells in body rows, no header row) become HTML tables**; simple ones become GFM tables.
- **Smileys become emoji; DokuWiki typography entities (`->`, `(c)`, `...`) become the Unicode characters** at conversion time, so the renderer does no text substitution.
- **`~~NOTOC~~` becomes frontmatter `toc: false`**; `~~NOCACHE~~` is dropped.

## Storage

- **The namespace start page stays `start`** (`foolslanding/start.md`), as in DokuWiki.
- **Media lives in `lodge-data/_media/`, mirroring DokuWiki's paths, and is git-ignored.** The content-hash store with a manifest in git, from the plan, is deferred: the path mirror is simpler and enough for now. Revisit before switch-over.
- **Media history is not imported**, only current media files. Page history is.
- **Special routes live under `/_/`** and page ids may not start with `_`, so they never collide.

## Server

- **The index (titles, backlinks, listings, created/modified dates, search) is in memory**, rebuilt at start-up from the files plus a single `git log` pass. SQLite from the plan is not needed at 1,230 pages. Revisit if start-up gets slow.
